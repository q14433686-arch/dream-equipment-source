# Dream Equipment / 圆梦装备

![Dream Equipment cover](docs/assets/dream_equipment_cover.png)

Standalone Fabric mod project for Minecraft 26.3. The project cover art is stored at `docs/assets/dream_equipment_cover.png` and mirrored in resources as `assets/dream_equipment/cover.png`.

This project is separate from `yansheng-source`; that repository is only a workflow/API reference.

## Environment

- Minecraft `26.3`
- Fabric Loader `0.19.5`
- Fabric API `0.160.7+26.3`
- Fabric Loom `1.17.20`
- Java `25+`
- Gradle wrapper `9.5.1`

## Build & CI

```bash
# Static consistency, resource drift, JSON schema, asset & balance gate (no Gradle/JDK required)
bash scripts/check_release_consistency.sh --strict

# Full Gradle build (requires JDK 25 and Maven network access)
./gradlew --no-daemon build --rerun-tasks
```

GitHub Actions workflow templates (`compile-check.yml`, `build.yml`, `consistency.yml`) are staged in `docs/ci/` (see [`docs/ci/README.md`](docs/ci/README.md)), and the 26.3 porting report is at [`docs/reports/PORTING_26_3_REPORT.md`](docs/reports/PORTING_26_3_REPORT.md).

## Current status

Current baseline: 426 custom items across 69 JSON-defined equipment families (including 9 new Minecraft 26.2/26.3 material families: `poplar`, `poplar_log`, `sulfur`, `cinnabar`, `shelf_mushroom`, `resin`, `nautilus_shell`, `straw`, and `cushion`). Registration/content is data-driven from `equipment_families.json`; set-effect values and rule tables are data-driven from `set_effects.json`.

Latest checked state: 2026-07-03 vanilla material shield pass after project cover art, vanilla shield recipe disable, custom shield textures/effects, and plank component-mapping art pass. Generator drift check, validators, balance audit, and Gradle build pass with Java 25. Repair tags are generated from JSON-owned `repair_ingredients` when present; coal and wood/log-like armor fuel values are generated from JSON-owned `fuel_burn_time_per_material`; redstone equipment uses JSON-tuned short equip/step pulses with a redstone wire evaluator mixin for dust-line propagation. Wood/plank/log/stem worn equipment layers are regenerated by `scripts/generate_wood_worn_textures.py`; all plank families use component-local vanilla plank mapping, while log/stem families remain on the vanilla-source baseline. Shields are implemented for all Dream Equipment families plus copper/golden/diamond/netherite vanilla-material shield families, with data-driven gameplay effects and material-adapted custom base textures; vanilla shield crafting is disabled to avoid recipe conflicts. Selected cover art is available at `docs/assets/dream_equipment_cover.png`.

- **Minecraft 26.2 / 26.3 Material Expansion**:
  - **Poplar & Poplar Log (`poplar`, `poplar_log`)**: 4-piece armor + shield sets with fuel burn time and drifting 3-color autumn leaf particles (`RED/ORANGE/YELLOW_POPLAR_LEAVES`) + Slow Falling / Speed / Resistance
  - **Sulfur (`sulfur`)**: 4-piece armor + 6 stone-tier tools (`sword`, `pickaxe`, `axe`, `shovel`, `hoe`, `spear`) + shield with Potent Sulfur Geyser thermal launch (`SULFUR_BUBBLES` + `GEYSER_ERUPTION_START`), Nausea/Poison cleansing, combustible fuel (`400` ticks/unit), and brittle rock physics
  - **Cinnabar (`cinnabar`)**: 4-piece armor + 6 stone-tier tools + shield with Cinnabar Alchemy Ward (`Regeneration` + continuous Poison & Wither cleansing), stone armor physics, and magic/undead shield ward
  - **Shelf Mushroom (`shelf_mushroom`)**: Elastic fungal `shelf_mushroom_boots` (≤8 block safe fall & `SHELF_MUSHROOM_BOUNCE` rebound with no passive durability decay) + `shelf_mushroom_shield`
  - **Resin (`resin`)**: Amber resin 4-piece armor + sword + spear + shield that coats melee attackers with `Slowness II` (`FALLING_HONEY` particles)
  - **Nautilus Shell (`nautilus_shell`)**: Deep-sea 4-piece armor + iron-tier spear + shield granting vanilla `minecraft:breath_of_the_nautilus`, `Dolphin's Grace`, and `Conduit Power`
  - **Straw & Cushion (`straw`, `cushion`)**: Lightweight rural `straw` armor (`草帽`, `草编蓑衣`, `草编护腿`, `草鞋`) + shield and plush `cushion_boots` + `cushion_shield` (`#minecraft:cushions`) with fall cushioning

Textures are original generated assets using Vanilla+/vanilla-style direction as reference only.
