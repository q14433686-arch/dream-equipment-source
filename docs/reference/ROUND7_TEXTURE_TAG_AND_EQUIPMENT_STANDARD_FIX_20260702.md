# Round 7 Texture, Tag, and Equipment Standard Fix — 2026-07-02

## User feedback

The user pointed out four issues:

1. Only emerald tool textures had been replaced; other material tools still used old generated icons.
2. Worn armor / equipment layer textures were wrong and needed to follow the current-version equipment texture specification.
3. Tools/weapons were missing vanilla item tags, so first-person animation mods could not recognize them.
4. Spear inventory/render icon and in-hand/held texture were mixed up. The new supplied spear image is the render icon, not the held texture.

## Current-version equipment texture research

Checked the local MC 26.1.2 jar resources. Current armor equipment uses:

- `assets/<namespace>/equipment/<material>.json`
- layer keys:
  - `humanoid`
  - `humanoid_baby`
  - `humanoid_leggings`
- texture paths:
  - `assets/<namespace>/textures/entity/equipment/humanoid/<texture>.png`
  - `assets/<namespace>/textures/entity/equipment/humanoid_baby/<texture>.png`
  - `assets/<namespace>/textures/entity/equipment/humanoid_leggings/<texture>.png`
- vanilla humanoid equipment textures are 64×32.

To fix our worn layers, all material equipment textures were regenerated by recoloring the vanilla `diamond` equipment UV templates for `humanoid`, `humanoid_baby`, and `humanoid_leggings`. This preserves the current-version UV layout instead of using rough hand-drawn rectangles.

## Tool texture changes

Reused the uploaded emerald tool templates as material silhouettes and recolored them for every matching material tool/weapon icon:

- swords
- axes
- pickaxes
- shovels
- hoes

This applies to all relevant material families, not only emerald.

## Spear model correction

Checked vanilla 26.1.2 spear item resources:

- `assets/minecraft/items/diamond_spear.json` uses a display-context `select` model.
- GUI/ground/fixed/on_shelf use `minecraft:item/diamond_spear`.
- Other contexts use `minecraft:item/diamond_spear_in_hand`.
- `diamond_spear.png` is 16×16 render/inventory art.
- `diamond_spear_in_hand.png` is 32×32 held/in-hand art.

Applied the same structure to custom spears:

- `assets/dream_equipment/items/<material>_spear.json` now selects render vs in-hand model.
- `assets/dream_equipment/models/item/<material>_spear.json` uses the render icon.
- `assets/dream_equipment/models/item/<material>_spear_in_hand.json` uses the in-hand texture.
- The newly supplied `120px-Diamond_Spear_JE1_BE1.webp` is used as the render icon base.
- The earlier held spear image is used as the in-hand base.
